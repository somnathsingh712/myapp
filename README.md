# nodeapp

Minimal Node.js app with Express.

Install dependencies:

```bash
npm install
```

Run:

```bash
npm start
```

Dev (auto-restart):

```bash
npm run dev
```

Interactive landing page served at the project root. API endpoints:

- `GET /api` — greeting JSON
- `GET /api/health` — basic health info
- `POST /api/echo` — echo posted JSON

Open http://localhost:3000 after running the server.
